# 校园二手交易微信小程序

## 打开方式

1. 打开微信开发者工具。
2. 导入 `miniprogram` 目录。
3. AppID 使用测试号或 `touristappid`。
4. 确认后端服务已启动：`http://localhost:8080`。

## 覆盖页面

- 首页：商品搜索、分类、商品列表、发布入口。
- 商品详情：收藏、聊一聊、立即购买。
- 确认面交：选择面交信息并生成待付款订单。
- 订单：模拟支付、确认收货。
- 求购：发布求购、查看求购列表。
- 消息：查看会话、发送咨询、会话内生成并支付待付款订单。
- 我的：登录状态、买入订单、我的发布、卖出订单、收藏和地址。
- 发布：发布闲置、发求购、查看发布管理入口。
